shamash

RustUpdated 2026-11-17Main project

A Discord music bot you talk to. Say “groovy, play Sodade by Cesária Évora” in voice chat and it plays.

Only a small voice detector runs all the time. The wake model runs while someone is talking, and the large model only on what came after the wake word, so it stays cheap on an always-on box.

Requests are matched against YouTube Music's song catalog, so the artist's own upload beats a remix. When it isn't sure, it asks, and it remembers your answer next time.

What works

  • ✓Wake word and speech recognition on the host
  • ✓Whole albums, song memory, /play suggestions
  • ✓Joins and leaves the voice channel by itself

beeDB

Node.jsUpdated 2026-10-26Archived

A distributed key-value database in Node.js, built for a Distributed Systems course.

A reverse proxy hashes each key with MD5 and sends the request to the shard that owns it. Inside a shard, replicas elect a leader with Raft, and writes go through two-phase commit, so every replica applies a write or none do.

Finished course project, kept as an archive. The full technical report is in the repo.

B450 firmware research

Python, shellUpdated 2026-11-12

Notes and tools from taking apart the BIOS of a Gigabyte B450 AORUS PRO, to see if coreboot could replace it. It can't: AMD's signed blobs, the chipset's own firmware and the missing AM4 support all get in the way. A side result is tinylinux, a 2 MiB LinuxBoot-style boot menu, tested in QEMU only.
